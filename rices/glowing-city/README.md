# Glowing City

![Desktop](screenshots/desktop.png)

- **Wallpaper:** a blue neon city at night.
- **Colors:** dark mode, pure black background, white text, grey accent
  (`#8D8D8D`). The same palette as [`onyx`](../onyx/README.md), with every
  shade produced by COSMIC's own color picker.
- **Layout:** unchanged. This rice sets colors and wallpaper only, so your
  panel and dock stay as they are.

Tested on Arch Linux. Not tested on Pop!_OS or Fedora.

## Extras

None.

## Install

From the repo folder (see the [main README](../../README.md#install) for the
full steps):

```bash
./switch-rice.sh glowing-city
```

## Uninstall

```bash
./switch-rice.sh --restore
```
