# Glowing City rice

One of several rices in this repo — see the [top-level README](../../README.md) for
the full list.

![Desktop](screenshots/desktop.png)

**Live snapshot, 2026-09-29, Arch Linux + COSMIC.** This is what the
[`onyx`](../onyx/README.md) rice turned into after daily use: the same
pure-black background and grey (`#8D8D8D`) accent, but with every derived
shade regenerated by COSMIC Settings' own accent picker (which closes the
hand-derived-shades caveat in onyx's README), and a blue-tinted version of
osaka-jade's glowing-city wallpaper.

## What this rice looks like

**Wallpaper** — `cosmic/com.system76.CosmicBackground/v1/all`, points at
`~/Pictures/1-glowing-city-blue-h60.jpg`, our own blue-tinted edit of
[`osaka-jade`](../osaka-jade/README.md)'s green neon cityscape (`1-glowing-city.jpg`),
made for this rice.

**Theme** — dark mode, pure-black/grey palette from onyx; COSMIC-generated
hover/pressed/selected shades in `cosmic/com.system76.CosmicTheme.Dark/v2/`.

**Panel/dock** — same layout as onyx (the tracked file set is identical to
onyx's, so switching between the two only changes colors and wallpaper).

**GTK3** — no `gtk-theme` file, so `switch-rice.sh` uses the default
`adw-gtk3-dark`.

## Applying it

```bash
./switch-rice.sh glowing-city
```

The wallpaper image isn't in this repo. On Greg's machines it's restored by
[arch-cosmic-hyprland](https://github.com/ggregoro/arch-cosmic-hyprland)'s
`install.sh`, which copies it to `~/Pictures` and rewrites the path for your
own `$HOME`. Doing it by hand: put any image at that path, or edit `source:`
in `cosmic/com.system76.CosmicBackground/v1/all`.
